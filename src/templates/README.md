# Local-intent template source

Use `prompts/templates.md` after identifying the active theme/page builder. Draft
classic PHP or block HTML templates accordingly; they are not interchangeable.
The owner reports Hello Elementor. Inspect actual Elementor templates and Free/Pro
availability before selecting a format. Elementor JSON exports/proposals can live
here, but importing and assigning them in WordPress is a separate approved staging
operation. Do not map Elementor layout JSON to a theme folder expecting it to render.
Use one useful primary page per service intent rather than a mass location generator.
Paoli/location/service statements must describe the confirmed practice accurately.

Uploading a template does not create or assign a page. Template assignment, page
content, titles, canonicals and links require review and exact staging approval.
