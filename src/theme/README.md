# Theme integration source

Keep local, reviewed integration files here after inspecting the actual active theme.
Prefer the existing child theme. Inspect the real `functions.php`, `style.css`,
`theme.json`, hooks and template hierarchy before choosing an integration route.
Never substitute a standalone snippet for the site's complete `functions.php`.

The owner reports Hello Elementor as active. Its actual version/directory and any
child theme remain unverified; do not use the parent theme as the upload target.
No child-theme slug, production path or deployable loader has been assumed.
New-theme files/activation and any include edits are separate approved staging actions.
See [WordPress child-theme guidance](https://developer.wordpress.org/themes/advanced-topics/child-themes/).
