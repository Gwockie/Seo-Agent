# Performance source

Place small reviewed PHP/JS/CSS performance changes here after `prompts/performance.md`.
Begin with a script/dependency inventory and comparable mobile baseline. Preserve
booking/contact forms, navigation, consent, accessibility and script dependencies.
Inspect existing caching/optimization settings before recommending changes.

Integration snippets must be included from reviewed actual child-theme code. Never
upload a fragment over `functions.php` or edit a vendor theme by default. Each
optimizer setting or cache purge is a separately enumerated staging write.
